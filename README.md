<h1 align="center">🐼🎂 Panda Birthday Special (Gg🐼) 🎂🐼</h1>

A warm, animated birthday surprise built for **Badi Sister (Gg🐼 / Panda)**: part digital letter, part memory gallery, part interactive celebration. This Next.js application opens like a storybook, progressing through a panda promise envelope, royal birthday cake with candle blow-out, balloons, elder-sister shayari reveal, blooming lotus flower, panda gift box with particle bursts, and finally a grand celebration page with wishes, photos, bamboo groves, and love.

> 🎋 Crafted as a heartfelt birthday experience for an incredible elder sister. 🎋

---

<h2 align="center">🌷 What It Includes</h2>

- 💌 **Panda Promise Envelope:** Interactive envelope with cute panda ears, blinking eyes, snout, paws, glowing hearts, and wax seal with an embossed panda paw (`🐾`).
- 🎂 **Royal Panda Birthday Cake:** 3-tier emerald & gold cake scene with panda cameos (*Royal Panda, Bamboo Panda, Cozy Panda*), engraved plaque *"Happy Birthday Gg🐼🥰"*, interactive candle blow, smoke wisps, and a wish-granting celebration.
- 🎈 **Balloon & Sister Shayari Stage:** Interactive physics balloons with pop effects, revealing a touching handwritten Hindi Shayari envelope for Badi Sister, transforming into a blooming lotus.
- 🎁 **Panda Mascot & Gift Box Stage:** Cozy stage featuring a custom vector Panda mascot holding bamboo, interactive 3D gift box with liftable lid, and a 32-particle explosion of emerald leaves, hearts, and golden stars.
- 🌸 **Grand Website Celebration:** Full-scale interactive showcase with bamboo hero banner, lotus flower garden, 6 elder sister wishes, 14-photo Polaroid memory gallery, deeply moving brother-to-sister letter, orbiting crown, and tri-color ripple rings with synchronized confetti.
- ✨ **Canvas Physics & 3D Shaders:** Canvas starfield sparkles, falling petals and bamboo leaves, Three.js point particle clouds, and responsive layouts for mobile, tablet, and desktop.

<h2 align="center">🗂️ Project Structure</h2>

```text
app/
  page.js                  Main staged birthday story and showcase website
  layout.js                Root layout, metadata, and font definitions
  globals.css              Main page styling, keyframes, and responsive CSS
  cake-gift.css            Cake and gift stage styling and 3D perspectives
  EnvelopePromise.js       Stage 1: Opening panda promise envelope
  PandaCakeScene.js        Stage 2: 3-tier birthday cake SVG scene
  CakeHeartAnimation.js    Stage 2: Parametric canvas heart trail animation
  cakeSparkles.js          Stage 2: Starfield sparkle data
  BalloonRoseStage.js      Stage 3: Balloon pop, shayari, and blooming lotus stage
  BearGiftStage.js         Stage 4: Vector panda mascot and 3D gift box stage
  HeartParticles.js        Three.js canvas heart particle background
  GiftBoxParticles.js      Three.js canvas gift box ambient particles

Images/
  Local memory gallery photos

assets/
  Demo preview buttons and icons
```

<h2 align="center">🚀 Getting Started</h2>

📦 Install dependencies:

```bash
npm install
```

🧁 Run the development server:

```bash
npm run dev
```

🌐 Open the app in your browser:

```text
http://localhost:3000
```

🏗️ Build for production:

```bash
npm run build
```

🎉 Start the production build:

```bash
npm run start
```
